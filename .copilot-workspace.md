# Requirements & Test Management Tool - Development Context

## Project Purpose
Enterprise tool for managing requirements and test cases with full traceability between customer needs and verification activities.

## Technology Stack
- **Frontend**: Blazor WebAssembly with MudBlazor components
- **Backend**: .NET 8 Web API with Entity Framework Core
- **Database**: SQL Server with comprehensive indexing
- **Authentication**: Custom Identity Server integration
- **Testing**: Multi-layered testing strategy (E2E, Component, Unit, Load)

## Development Guidelines
1. **Performance First**: All queries use AsNoTracking() for read operations
2. **Comprehensive Error Handling**: Every API endpoint has structured error responses
3. **Pagination Standard**: Use PagedResult<T> for all list operations
4. **Documentation**: XML docs required for all public APIs
5. **Testing**: New features require corresponding tests at appropriate levels
6. **Security**: Authentication required for all endpoints except health checks

## Common Tasks
- Adding new CRUD endpoints for domain entities
- Implementing search and filtering capabilities
- Creating Blazor pages with data binding and validation
- Writing comprehensive test coverage
- Performance optimization of database queries
- Integration with external systems
