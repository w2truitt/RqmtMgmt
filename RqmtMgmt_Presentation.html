Project Overview

  • Web-based enterprise tool for managing requirements and test cases
  • Built for Product Owners, Engineers, and QA Teams
  • Modern architecture: Blazor WebAssembly + .NET 8 Web API
  • Deployed on Kubernetes (Rancher Desktop)
  • Comprehensive test coverage: 732 automated tests
  • Full traceability from requirements to test execution

Technical Architecture

  • Frontend: Blazor WebAssembly (C#) - Modern SPA framework
  • Backend: .NET 8 Web API - High-performance RESTful API
  • Database: SQL Server with Entity Framework Core
  • Authentication: Duende IdentityServer with OAuth 2.0/OIDC
  • Containerization: Docker containers orchestrated by Kubernetes
  • Security: HTTPS/TLS with certificate management
  • Shared Library: RqmtMgmtShared for type-safe DTOs
