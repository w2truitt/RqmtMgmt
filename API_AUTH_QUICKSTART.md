# Quick Start: API Authentication\n\n## TL;DR - Get JWT Token and Call API\n\n```bash\n# 1. Get access token (same credentials as backend.LoadTests)\nTOKEN=$(curl -k -s -X POST \"https://rqmtmgmt.local/connect/token\" \\\n  -H \"Content-Type: application/x-www-form-urlencoded\" \\\n  -H \"Accept: application/json\" \\\n  -d \"grant_type=client_credentials&client_id=rqmtmgmt-backend&client_secret=backend-secret&scope=rqmtmgmt.api\" \\\n  | jq -r '.access_token')\n\n# 2. Use token to call API\ncurl -k -s -H \"Authorization: Bearer $TOKEN\" \\\n  -H \"Accept: application/json\" \\\n  \"https://rqmtmgmt.local/api/Dashboard/statistics\" | jq .\n```\n\n## Authentication Credentials\n\n**From backend.LoadTests/utils/auth-helpers.js:**\n- **Client ID:** `rqmtmgmt-backend`\n- **Client Secret:** `backend-secret` \n- **Scope:** `rqmtmgmt.api`\n- **Token URL:** `https://rqmtmgmt.local/connect/token`\n\n## Swagger UI Issue\n\nThe redirect error you mentioned occurs because:\n\n1. **Swagger UI uses a different OAuth2 flow** (Authorization Code with PKCE)\n2. **It requires user login**, not client credentials\n3. **Client ID for Swagger:** `swagger-ui` (not `rqmtmgmt-backend`)\n\n**Solution:** Use the direct API approach above instead of trying to authenticate through Swagger UI.\n\n## Available Scripts\n\n- `./test-api-auth.sh` - Complete authentication test\n- `node swagger-auth-test.js` - Playwright automation (requires npm install)\n\n## Key API Endpoints\n\n- `/api/Dashboard/statistics` - Dashboard data\n- `/api/Projects` - Projects list\n- `/api/Requirement` - Requirements\n- `/api/TestSuite` - Test suites\n- `/api/TestCase` - Test cases\n\n## Full Documentation\n\nSee `SWAGGER_AUTHENTICATION_GUIDE.md` for complete details.\n
