# Back-End Project Structure (.NET 8 Web API)

## Architecture Overview
This backend follows Clean Architecture principles with dependency injection and performance optimizations.

## Folder Structure
- **Controllers/**: REST API endpoints with comprehensive error handling
- **Models/**: Domain entities mapped to database tables
- **Data/**: EF Core database context, migrations, and configurations
- **Services/**: Business logic layer implementing interfaces from RqmtMgmtShared
- **Extensions/**: Extension methods and helper utilities
- **Middleware/**: Custom middleware for logging, error handling
- **Migrations/**: EF Core database migrations
- **Configuration/**: Dependency injection setup and application configuration
- **Program.cs**: Application entry point with service registration
- **appsettings.json**: Configuration files for different environments

## Key Patterns
- **Performance Optimized**: Uses AsNoTracking(), projections, and efficient queries
- **Pagination**: All list endpoints return PagedResult<T> with filtering and sorting
- **Error Handling**: Comprehensive try-catch blocks with structured logging
- **Authentication**: Integrated with Identity Server for user management
- **Documentation**: Full XML documentation on all public APIs
