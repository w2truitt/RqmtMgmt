# GitHub Copilot Configuration for RqmtMgmt

## Project Context
This is a Requirements & Test Management Tool built with:
- **Frontend**: Blazor WebAssembly (C#)
- **Backend**: .NET 8 Web API
- **Database**: SQL Server with Entity Framework Core
- **Testing**: E2E (Playwright), Component (bUnit), Unit (xUnit)
- **Architecture**: Clean Architecture with dependency injection

## Key Patterns
- Controllers use dependency injection for services
- Services implement interfaces from RqmtMgmtShared
- DTOs for data transfer between layers
- PagedResult<T> for pagination
- Comprehensive error handling and logging

## Common Operations
- CRUD operations with pagination and filtering
- User authentication and authorization
- Project-based data organization
- Test execution and result tracking

## Code Standards
- Async/await throughout
- Comprehensive XML documentation
- Performance optimizations (AsNoTracking, projections)
- Consistent error handling patterns
